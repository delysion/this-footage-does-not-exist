# Asset provenance

All eight source images were generated for this artwork using OpenAI image generation, under Codex-authored prompts that followed the artist's instructions. No output is presented as a photograph of a real event or installation. The artist has not yet approved the final image selection.

| Local source | Role and derivation |
| --- | --- |
| `assets/source/master-room-v2.png` | Master fictional concrete hall: red threshold, two distant reaching silhouettes, damaged black shoe with a stitched diagonal toe and brass eyelets. |
| `assets/source/master-shoe-v2.png` | Object close-up derived from the same master image and identifying damage. |
| `assets/source/room-romance-v2.png` | Edit of the master hall adding a candle and flower memorial. |
| `assets/source/room-security-v2.png` | Sequential edit retaining the memorial and adding evidence markers, a light and transparent packaging around the shoe. |
| `assets/source/room-revolution-v2.png` | Sequential edit retaining prior residues and adding monumental gesture banners. |
| `assets/source/room-commerce-v2.png` | Sequential edit retaining prior residues and adding a luxury vitrine, brass details and queue ropes. |
| `assets/source/room-final-v2.png` | Sequential edit retaining all residues, emptying the threshold and cooling the room. |
| `assets/source/gesture-hands.png` | Transparent composite of two reaching forearms, developed with the master room as a visual reference. The same pixels are reused in all four interpretations. Website and film code animate the two arms independently; individual fingers do not have a separately filmed or modeled performance. |

The WebP versions in `public/art/` are local derivatives made by `tools_optimize_images.py`. The poster and contact sheet combine these images with authored typography; the film moves, cuts and sequences the same assets. The new hand shot separates the single gesture source into independently timed arm layers and applies distinct framing, freezing, multiplication and looping to the four institutional cuts. It is an animated composite of an AI-generated still, not filmed human motion or a fully articulated hand animation. `public/tone-bed.wav` is generated from local Python synthesis by `tools_generate_sound.py`; no external recording is used.

Visual continuity was checked at a 3×2 contact-sheet scale and in real browser screenshots. Generative edits can still subtly vary material details between stills; this is an artistic limitation for final human review rather than proof of a photographed set.

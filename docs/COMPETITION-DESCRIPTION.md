# ELEVEN SECONDS. ZERO FRAMES. — competition description (draft)

Eleven seconds are absent from a fictional camera archive. One room, red doorway, two distant figures and damaged black shoe recur in four incompatible reconstructions. Romance turns the shoe into a memorial relic; Security packages it as evidence; Revolution raises the gesture into banners; Commerce displays the object as an exclusive product. Each account leaves its intervention in the room. When the viewer requests the original, image and sound stop for eleven real seconds. The room returns empty of figures, still full of institutional residues. Nothing about the event has been proven. Everything around it has been changed.

Interactive website and approximately 73-second experimental film. AI-assisted fictional scene imagery, authored cinematic editing and locally synthesized sound. Draft written with Codex assistance; final artist review of the current images, film and mix, and competition submission approval, are pending.

# ELEVEN SECONDS. ZERO FRAMES. — competition description (draft)

Eleven seconds are absent from a fictional camera archive. Romance, Security, Revolution and Commerce each return a persuasive version of the same red doorway, two figures, damaged black shoe and reaching gesture. The viewer can cut between their claims at the same instant. Each image changes the meaning of what appears to be evidence; none has a recorded source. Requesting the original abruptly removes image and sound. For eleven real seconds, only a clock crosses a nearly black screen; then the archive reports zero recovered frames. **ELEVEN SECONDS. ZERO FRAMES.** asks who gains the authority to define an event when representation is abundant and evidence is absent.

Interactive website and approximately 66-second experimental film. Original vector artwork and locally synthesized sound. Draft written with Codex assistance; final artist review of the updated media and competition submission approval pending.

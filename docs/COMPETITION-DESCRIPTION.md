# ELEVEN SECONDS. ZERO FRAMES. — competition description (draft)

Eleven seconds are absent from a fictional camera archive. One room, red doorway, two distant figures and damaged black shoe recur in four incompatible reconstructions. Romance turns the shoe into a memorial relic; Security packages it as evidence; Revolution raises the gesture into banners; Commerce displays the object as an exclusive product. Each account leaves its intervention in the room. When the viewer requests the original, image and sound stop for eleven real seconds. Later, the altered room returns. A hand reaches for the shoe and meets the glass around it. The hand withdraws; the display remains. No image has established what occurred in the missing interval.

Interactive website and two experimental film endings for artist comparison. The new alternate runs approximately 71 seconds and ends without a written verdict; the 73-second prior version remains available. AI-assisted fictional scene imagery, authored compositing/editing and locally synthesized sound.
